# TREASURE HUNT

거대한 육각판 위에서 **해적 · 산적 · 도적** 세 도둑 세력이 보물을 두고 겨루는 보드게임입니다.
의존성 없는 단일 HTML 파일이라 [`index.html`](index.html) 을 브라우저로 열면 바로 실행됩니다.

## 판

- 한 변이 작은 육각 **9칸**인 거대 육각판 — 총 **217칸**
- 작은 육각 하나가 하나의 좌표 `(q, r)` 이며, 보물이 나오는 장소가 됩니다
- **지형 바꾸기** 버튼으로 지형을 매번 새로 랜덤 분배합니다

| 지형 | 색 | 주인 세력 | 비율 |
|---|---|---|---|
| 바다 | 파랑 | 해적 | 약 20% |
| 산 | 회색 | 산적 | 약 16% (봉우리 ▲ 8곳) |
| 도시 | 빨강 | 도적 | 약 8% (서로 인접하지 않음) |
| 평야 | 노랑 | 없음 | 나머지 |

바다와 산은 씨앗을 판 전체에 흩뿌린 뒤 넓혀 덩어리로 생기고, 도시는 흩어져 배치됩니다.
세 세력의 시작 칸은 각자의 고향 지형 중 **서로 가장 멀리 떨어지는 조합**으로 정해집니다.

## 턴 — 행동 3개

한 턴에 아래 세 행동을 자유롭게 조합합니다. 중복 사용이 가능해서 이동을 3번 고르면 3칸을 갑니다.

1. **이동** — 인접한 한 칸으로
2. **능력** — 자기 지형 위에서만
   - 해적 / 바다 — 이어진 물길을 따라 최대 4칸
   - 산적 / 산 봉우리 ▲ — 집라인으로 다른 봉우리로
   - 도적 / 도시 — 은신, 다음 자기 턴이 끝날 때까지 위치 비공개
3. **획득** — 보물이 있는 칸에서

## 보물

- 카드 **50장**, 항상 **4장**이 앞면으로 공개되어 판 위의 좌표에 놓입니다
- 획득하면 그 카드는 사라지고 더미에서 1장을 뽑아 새 좌표에 공개합니다
- **더미가 바닥나는 순간 게임 오버**, 보유 보물의 값어치 합계가 가장 높은 세력이 승리합니다

## 약탈

같은 칸에서 조우하면 **그 칸 지형의 주인 세력**이 우세를 잡고, 상대에게서
가장 비싼 것도 가장 싼 것도 아닌 **중간 값어치**의 보물 1장을 빼앗습니다.

- 예) 산 지형에서 산적이 도적·해적과 조우 → 산적이 각각에게서 중간 값어치 보물을 약탈
- 평야이거나 그 지형의 주인 세력이 조우에 없으면 약탈은 일어나지 않습니다
- 보유 보물이 2장 이하면 전부 최고가/최저가라 빼앗길 카드가 없습니다
- 조우하면 은신은 즉시 풀립니다

점수 패널의 값어치 칩 중 **금색 ◆ 칩이 현재 약탈 대상**입니다.

## 플레이 방식

시작 화면에서 고릅니다.

- **3인 플레이** — 한 화면에서 번갈아 진행. 은신 중에는 턴이 넘어갈 때 가림막이 뜹니다
- **AI 대전** — 한 세력을 맡고 나머지 둘은 AI가 조작

AI는 ① 발밑 보물 획득 → ② 자기 지형에서 털 만한 상대 덮치기 → ③ 2칸 이상 이득이면 능력 사용
→ ④ 최단경로로 가장 가까운 보물, 순서로 판단합니다.

## 디자인 시스템

[`Typography & colors.pdf`](Typography%20&%20colors.pdf) 의 Nickelfox 보물찾기 시스템을 CSS 토큰으로 옮겼습니다.

- **서체** Inter — Regular 400 / Medium 500 / Semibold 600 / Black 900
- **색상** `#00B8B8` · `#064A57` · `#000000` · `#FFFFFF`
- **표면** 반투명 글래스 패널 (`rgba(255,255,255,.07)` + `backdrop-filter: blur(16px)`)
- radius · space · elevation · type scale을 `:root` 변수로 정의해 값 하나로 전체를 조정할 수 있습니다

지형 색은 규칙상의 파랑/회색/빨강/노랑을 유지하되 팔레트와 어울리도록 톤을 맞췄습니다.
